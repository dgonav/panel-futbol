# Panel de Resultados de Fútbol con React

Aplicación web hecha con React (Vite) para registrar resultados de partidos de un torneo y ver la tabla de posiciones, que se calcula automáticamente.

**Demo en línea:** https://dgonav.github.io/panel-futbol/

- Aplicación desplegada: https://dgonav.github.io/panel-futbol/

- Explicación (PDF): [entregables/Actividad_20_Panel_Futbol.pdf](entregables/Actividad_20_Panel_Futbol.pdf)

## Requisitos

- Node.js 18 o superior (incluye npm)

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio:
   ```bash
   git clone https://github.com/dgonav/panel-futbol.git
   cd panel-futbol
   ```
2. Instalar las dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abrir en el navegador la dirección que muestra la terminal (normalmente http://localhost:5173).
